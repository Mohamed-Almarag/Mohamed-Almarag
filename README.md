Delivered bidding and tender systems, freelancing marketplaces, e-learning, and healthcare platforms, including multilingual RTL interfaces, real-time features, live-streaming, and payment gateway integrations. Author of Locale Guard, an open-source GitHub Action that catches translation bugs in pull requests.

## Open Source & Products

**[Locale Guard](https://github.com/Mohamed-Almarag/locale-guard)**: open-source GitHub Action that checks translation files on every pull request for vue-i18n, Nuxt, next-intl, react-intl, and i18next. Runs in CI on production projects, and found the translation bugs fixed in the contributions below. Available on the [GitHub Marketplace](https://github.com/marketplace/actions/locale-guard).

**[Smart Admin Panel](https://github.com/Mohamed-Almarag/smart-admin-showcase)**: commercial schema-driven admin template for Vue 3 with a code-generating CLI. [Live demo](https://smart-admin-panel-demo.vercel.app) · [Docs](https://smart-admin-panel-docs.vercel.app)
